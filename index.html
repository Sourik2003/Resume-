About Me

Hi, I’m Sourik Maity — a passionate and curious Web Developer who loves creating clean, modern and animated websites. I enjoy turning ideas into working digital experiences that look great and feel smooth to use.


I started learning web development because I’m fascinated by how a few lines of code can build something real, something that people can interact with. Now, I focus on improving my skills every day — from HTML, CSS and JavaScript, to Python and logical problem solving.
